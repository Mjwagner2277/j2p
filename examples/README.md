# Examples

This folder intentionally contains one maintained end-user walkthrough:

- `large-scenario/README.md`

Older small samples and one-off tutorial folders have been removed so the examples do not teach stale behavior. The large scenario is the source of truth for training and client walkthroughs.

The large scenario includes:

- 1,200-line baseline and follow-on Jira CSV exports
- a full YAML configuration
- generated manager-review reports
- per-project-key CSV outputs
- expected review cases for color and report validation

Start with `large-scenario/README.md` before adapting j2p to a live Jira export.
